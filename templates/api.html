Quick Integration Guide

Endpoint URL

{{ url_root }}api/reseller_v1.php

Send POST request with: api_key, action, product_id, duration.

BALA MOD XYZ V1 ke liye android_id bhejna zaroori hai, jabki V2 ke liye android_id ki zaroorat nahi hai.

RESELLER API CODE (PHP)

$data = [
    'api_key'    => '{{ user.api_key }}',
    'action'     => 'buy',
    'product_id' => 'PRODUCT_PID_ID',             // Exact Product PID
    'duration'   => '1 DaYs',                       // Duration (e.g. 1 Hours, 1 DaYs, 7 DaYs)
    'android_id' => '0b9b969bc2e7997b'             // MANDATORY for Device Bound Products
];

$headers = [
    'Content-Type: application/x-www-form-urlencoded',
    'x-master-key: {{ master_key }}'
];

$ch = curl_init('{{ url_root }}api/reseller_v1.php');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => http_build_query($data),
    CURLOPT_HTTPHEADER     => $headers,
    CURLOPT_TIMEOUT        => 20,
    CURLOPT_SSL_VERIFYPEER => false,
    CURLOPT_SSL_VERIFYHOST => false
]);
$response = curl_exec($ch);
curl_close($ch);
echo $response;

Important Configuration Checklist

  • PID Verification: Apne reseller panel me Product ka PID (Product ID) Sahi rakhein.
  • Duration Name: Duration exact Hours ya Day paas karein jaisa table me likha hai.
  • Android ID System: V1 products ke liye ndroid_id bhejye. V2 me bina ndroid_id ke key auto-generate ho jaati hai.
